# Arrays & Strings

This folder contains my solutions to **Arrays and Strings** problems from various coding platforms, primarily **LeetCode**. The goal of this section is to build strong problem-solving skills by mastering the fundamental techniques used in interviews.

## 🎯 Objectives

* Build intuition for array and string manipulation.
* Learn multiple approaches to solve the same problem.
* Improve time and space complexity.
* Prepare for coding interviews.

## 📚 Topics Covered

* Array Traversal
* String Manipulation
* Prefix Sum
* Two Pointers
* Sliding Window (Fixed & Variable)
* Hashing
* Frequency Count
* Sorting
* Binary Search on Arrays
* Matrix Problems
* Simulation
* Greedy Basics

## 📝 Problem Structure

Each solution includes:

* Problem name as file name as .py file
* Solution of leetcode problem inside the file
